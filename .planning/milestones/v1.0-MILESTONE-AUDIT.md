## Cross-Phase Integration

Integration checker found **zero code-level wiring breaks**. Every phase exports the surface its downstream consumer imports. Highlights:

- **Pipeline tick chain** (`pipeline.py:288-330`): typed DTOs flow Frame → Detection → TrackedSubject → MotionState → FramingTarget → angle → MotorCommand. All DTOs are frozen pydantic / dataclass. No internal-state cross-stage access.
- **Lifecycle wiring**: 5 buttons + 5 hotkeys (S/P/H/E/Q) all route through `PipelineThreadHost.submit(pipeline.<method>())`. E debounced on press; S/P/H/Q on release (Phase 7 P03 lock).
- **Heartbeat + recovery**: 200 ms heartbeat task lives in `ArduinoMotor.start()`. `READY:v2` mid-session triggers `_recover()` which re-issues settings + limits in-place.
- **Event bus**: `EventBusProcessor` → `_status_panel "Last error"` widget; fail-fast on missing `level` key (Phase 7 WR-06 fix).
- **Two-stage damping**: `Framer` (≈ 0.8 s) + `PanController` (≈ 0.6 s); critically-damped follower, no PID, no overshoot.
