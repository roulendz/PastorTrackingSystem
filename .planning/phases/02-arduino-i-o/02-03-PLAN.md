Internal contract:
- Single asyncio writer (TX_LOCK serializes heartbeat + command-sender producers).
- Single OS reader (RX thread; only place that calls transport.read_line).
- RX thread parses INTO `ProtocolEvent` and bridges to asyncio queue via `loop.call_soon_threadsafe(_enqueue, event)` — `_enqueue` runs on the loop thread, applies drop-oldest semantics on full queue (256-cap).
- Mid-session `Ready` event → recovery state machine:
  1. Set `_dispatch_paused = True`.
  2. Send S: from Config → wait for structured `Settings` ack (NOT `SettingsInfo`) within `arduino_ready_timeout_sec`.
  3. Send L: from Config → wait for `Limits` ack within `arduino_ready_timeout_sec`.
  4. Drain ONE trailing `SettingsInfo` ("SETTINGS: saved to EEPROM" — RESEARCH line 506) so the public events queue stays clean of recovery noise.
  5. Set `_dispatch_paused = False`. Resume.
  - Heartbeat continues throughout recovery (firmware-watchdog must stay satisfied).
  - Ack timeout → set `_latched_error = WatchdogResetError("recovery ack timeout")`; set `_state = FAULTED`; log `event="watchdog_recovery_failed", reason="ack_timeout"`; RETURN (do NOT re-raise — surface is the next `send_*` call which raises the latched WatchdogResetError).
- `Error` event from firmware → set state = FAULTED, set `_dispatch_paused = True`, set `_latched_error = FirmwareErrorReceived(code, message)`, surface via the events() stream as `Error` AND via raising `FirmwareErrorReceived` from the next `send_*` call (no auto-recover; CONTEXT.md Out-of-Scope).
- USB-disconnect / serial RX-thread exception → set `_latched_error = LinkLostError(f"link_lost: {exc}")` (NOT `FirmwareErrorReceived(ErrorCode[dot]NONE, ...)` — `ErrorCode.NONE` is the firmware sentinel for "no error" per protocol.h:68; reusing it for a host-side event corrupts the typed contract).

    Bridges the pure parser (arduino_protocol.py) and the transport
    (arduino_transport.py) into a working motor link. Owns the only
    threading↔asyncio bridge in the project: a daemon RX thread reads
    bytes, parses to ProtocolEvent, then crosses into the asyncio
    loop via loop.call_soon_threadsafe to enqueue a bounded queue.

    Concurrency invariants (CLAUDE.md rule 1, RESEARCH.md "Architecture
    & Concurrency"):
        - Single writer: only the asyncio loop calls transport.write,
          always behind self._tx_lock.
        - Single reader: only the RX daemon thread calls transport.read_line.
        - Bounded RX queue: maxsize=256, drop-oldest + WARN log on full.
        - Mid-session Ready event = MCU watchdog reset → re-issue
          settings + limits from Config → resume.
        - ERROR:N from firmware halts dispatch, requires manual reset
          (CONTEXT.md Out-of-Scope: no auto-recover).
        - Recovery ack timeout latches WatchdogResetError; the _recover
          task does NOT re-raise (deterministic surface = next send_*).
        - USB-disconnect / RX-thread serial exception latches LinkLostError
          (NOT FirmwareErrorReceived with ErrorCode.NONE — that sentinel
          is the firmware's "no error" code per protocol.h:68 and must
          not be reused for host-side events).

        """Mid-session READY:v2 recovery failed (settings/limits ack timeout). — IO-ARD-06"""

    class FirmwareErrorReceived(ArduinoError):
        """ERROR:<code> from firmware — halts tracking. — IO-ARD-07"""
        def __init__(self, code: ErrorCode | int, message: str) -> None:

            self.message = message

        """USB disconnect mid-session. — IO-ARD-07 (ERROR-class halt). Distinct surface

        for this — ErrorCode.NONE is the firmware's "no error" sentinel
        (protocol.h:68) and must not appear on host-originated faults."""

    `async def start(self) -> None`:
    1. Guard: if `_state != DISCONNECTED`, raise ArduinoError("start() called twice").

    5. Set `_state = RUNNING`. Log "handshake_complete" with version + elapsed_ms.
    6. Spawn `self._rx_thread = threading.Thread(target=self._rx_loop, name="arduino-rx", daemon=True)`. Start it.
    7. Spawn `self._heartbeat_task = asyncio.create_task(self._heartbeat_loop())`.
    8. Set `_dispatch_paused = False`.

        if line is None:

        try:

        motor: ArduinoMotor,
        target_state: _MotorState,
        timeout: float = 1.0,
    ) -> None:
        """Poll motor.state at 10 ms cadence until target_state or timeout. — WARN 9.

            f"(current: {motor.state})"
