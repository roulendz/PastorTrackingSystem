1. **Skip if no person detected** -- `if not obCurrentSample.bPersonWasDetected: return` (Phase 4 will add hold logic here)

2. **Confidence gate (MOTN-04):**
   ```python
   flConfidenceScale = compute_confidence_scale_factor(
       obCurrentSample.flPersonConfidenceScore,
       self.flConfidenceHoldThreshold,
       self.flConfidenceFullThreshold
   )
   if flConfidenceScale <= 0.0:
       # Below hold threshold: freeze camera at current position
       # Accumulate low-confidence timer -- sustained low confidence triggers home return
       # (Per CONTEXT.md: "treat it like soft detection loss -- hold for timeout, then S-curve home")
       self._flLowConfidenceTimer += flDeltaTimeSeconds
       if self._flLowConfidenceTimer >= self.flConfidenceLowTimeoutSeconds:
           # Sustained low confidence exceeded timeout -- trigger home return
           # Feed the HomeReturnController as if person is in safe zone (angle 0.0)
           # so it transitions through SAFE_ZONE_DELAY -> RETURNING_HOME -> AT_HOME
           eHomeState = self._obHomeReturnController.update(
               0.0,  # Treat as if person is at home (in safe zone)
               self.flDeadbandDegrees,
               flDeltaTimeSeconds,
               obCurrentSample.flMotorAngleDegrees
           )
           if eHomeState == HomeReturnState.RETURNING_HOME:
               flNewTargetAngle = self._obHomeReturnController.get_target_angle()
               # Apply S-curve profiling and send command (same as step 9-10 below)
               flDesiredVelocity = (flNewTargetAngle - obCurrentSample.flMotorAngleDegrees) / flDeltaTimeSeconds
               flSmoothedVelocity = self._obMotionProfiler.compute_smoothed_velocity(flDesiredVelocity, flDeltaTimeSeconds)
               flSmoothedTarget = obCurrentSample.flMotorAngleDegrees + flSmoothedVelocity * flDeltaTimeSeconds
               # Clamp and send (same safety limits as step 10)
               # ... (clamp to safety limits, check min delta, send_move_to_angle_command)
           elif eHomeState == HomeReturnState.AT_HOME:
               pass  # Camera locked at home -- output nothing
       return
   # Person detected with usable confidence -- reset low-confidence timer
   self._flLowConfidenceTimer = 0.0
   ```
   NOTE: The `flDeltaTimeSeconds` used in the confidence gate is computed BEFORE this step. Move the dt computation (step 7) ABOVE the confidence gate so dt is available here. The reordered flow is: step 1 (skip if no person) -> step 7 (compute dt) -> step 2 (confidence gate with timer) -> steps 3-6 (pose filtering and angle error) -> step 8 (home return) -> step 9 (S-curve) -> step 10 (clamp and send).

   IMPORTANT: When the low-confidence timer triggers a home return, the motor command path (S-curve profiling, clamping, sending) must follow the same logic as the normal home return path in steps 9-10. Extract the "clamp and send" logic from step 10 into a helper method `_send_profiled_motor_command(flTargetAngle, flCurrentAngle, flDeltaTimeSeconds)` to avoid duplication between the confidence-triggered home return and the normal home return path.

   if eHomeState == HomeReturnState.AT_HOME:
