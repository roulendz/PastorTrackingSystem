**Create `tests/conftest.py`** with shared fixtures:

1. `obSimulatedMotor` fixture:
   - Creates a `SimulatedMotorInterface` with default physics settings
   - Returns the motor instance
   - No background thread (tests call `advance_simulation()` explicitly for determinism)

2. `obSyntheticCamera` fixture (uses `tmp_path`):
   - Generates a test video file using `cv2.VideoWriter`:
     - 90 frames (3 seconds at 30fps), 1280x720, mp4v codec
     - A red circle (radius 30) moving linearly from x=320 to x=960 (left-to-right walk)
     - Green shoulder markers at +/- 40px from center circle
   - Creates a `CameraInterface(sVideoFilePath=str(video_path))`
   - Calls `open_camera_device()` and asserts success
   - Yields the camera
   - Calls `close_camera_device()` in teardown

3. `obTestConfig` fixture:
   - Creates `SystemConfiguration()` (uses updated defaults from Plan 01)
   - Overrides: `bAllowStartWithoutMotor = True`, `bEnableVisualization = False`, `bShowDebugInfo = False`
   - Returns the config

4. Helper function `generate_test_video(sOutputPath, iFrameCount=90, iWidth=1280, iHeight=720, iFramesPerSecond=30, flStartX=0.25, flEndX=0.75)`:
   - Generates a simple test video with a moving red circle and shoulder markers
   - Uses `cv2.VideoWriter` with `mp4v` fourcc
   - Returns the path to the created video file

5. `obMockPoseTracker` fixture:
   - Creates a mock PoseTracker that does NOT use MediaPipe (avoids heavy dependency in tests)
   - Instead, uses `unittest.mock.Mock` to create an object with the same interface
   - `detect_person_in_frame(frame)` returns a PoseResult with:
     - `bPersonWasDetected = True`
     - `flPersonCenterXPixels` = center of frame (640.0)
     - `flPersonCenterYPixels` = 360.0
     - `flPersonConfidenceScore` = 0.9
     - `vLandmarks = None`
   - This avoids requiring MediaPipe in test environment
   - Import PoseResult from pose_tracker to construct the return value

Ensure all fixtures use Hungarian notation. Add `import` statements for: pytest, cv2, numpy, unittest.mock.Mock, and all needed src modules.

**Create `tests/test_motor_simulation.py`:**

Tests for SimulatedMotorInterface physics:

1. `test_simulated_motor_does_not_teleport(obSimulatedMotor)`:
   - Command 10-degree move
   - Advance 1ms
   - Assert angle < 1.0 (did not teleport)
   - Advance 2000 x 1ms (2 seconds total)
   - Assert angle within 0.1 of 10.0 (reached target)

2. `test_simulated_motor_respects_velocity_limit(obSimulatedMotor)`:
   - Set max speed to 20.0 deg/s, acceleration to 100.0 deg/s^2
   - Command 90-degree move
   - Advance 5000 x 1ms, track max observed velocity
   - Assert max velocity <= 20.0 * 1.01 (1% tolerance for float)

3. `test_simulated_motor_decelerates_to_stop(obSimulatedMotor)`:
   - Command 5-degree move
   - Advance until motor reaches target (within 0.05 degrees)
   - Check velocity is near zero when at target

4. `test_simulated_motor_state_reports_moving(obSimulatedMotor)`:
   - Command a move
   - Advance a few steps
   - Assert `get_latest_motor_state().bMotorIsMoving` is True
   - Advance to completion
   - Assert `bMotorIsMoving` is False

5. `test_simulated_motor_home_command(obSimulatedMotor)`:
   - Move to 10 degrees (advance to completion)
   - Call `send_home_command()`
   - Advance to completion
   - Assert angle is approximately 0.0

**Create `tests/test_camera_interface.py`:**

Tests for video file camera input:

1. `test_camera_reads_from_video_file(obSyntheticCamera)`:
   - Read one frame
   - Assert frame is not None
   - Assert frame shape is (720, 1280, 3)

2. `test_camera_reads_all_frames_from_video(obSyntheticCamera)`:
   - Read 90 frames in a loop
   - Assert all 90 return non-None frames

3. `test_camera_loops_video_at_end(obSyntheticCamera)`:
   - Read 95 frames (90 in video + 5 more after loop)
   - Assert frame 91 (after loop) is not None
   - Assert frames continue after looping

4. `test_camera_frame_has_timestamp(obSyntheticCamera)`:
   - Read a frame
   - Assert timestamp > 0.0
   - Assert timestamp is a float

5. `test_camera_video_file_not_found()`:
   - Create CameraInterface with `sVideoFilePath="nonexistent.mp4"`
   - Assert `open_camera_device()` returns False

**Create `tests/test_fov_calculation.py`:**

Tests for FOV correctness:

1. `test_sony_ax700_fov_at_max_optical_zoom()`:
   - Calculate: `2 * math.atan(13.2 / (2 * 111.6))` in degrees
   - Assert result is between 6.5 and 7.0 degrees
   - Assert result is approximately 6.77 (within 0.05)

2. `test_pixel_to_degree_conversion_at_1280px()`:
   - Angle per pixel = 6.77 / 1280
   - Assert approximately 0.00529 (within 0.0001)
   - Verify: 100 pixels offset = ~0.53 degrees (within 0.05)

3. `test_default_config_has_correct_fov(obTestConfig)`:
   - Assert `obTestConfig.flFieldOfViewDegrees == 6.77`
   - Assert `abs(obTestConfig.flInitialAnglePerPixelDegrees - 0.00529) < 0.0001`

4. `test_fov_replaces_legacy_angle_per_pixel()`:
   - Previous value was 0.05 (implying 64-degree FOV)
   - Current value should be 0.00529
   - Assert they are NOT equal (confirming the fix was applied)

**Create `tests/test_pipeline_no_hardware.py`:**

Integration test for full pipeline without hardware:

1. `test_full_pipeline_runs_without_hardware(obSimulatedMotor, obSyntheticCamera, obTestConfig, obMockPoseTracker)`:
   - Create a `ProportionalController(1.0)` from `control.control_algorithm`
   - Create `TrackerController(obSimulatedMotor, obSyntheticCamera, obMockPoseTracker, obControlAlgorithm)`
   - Call `obTrackerController.apply_configuration(obTestConfig)`
   - Call `obTrackerController.start_tracking_mode()`
   - Execute 10 iterations of `execute_main_tracking_loop_tick()`
   - After each tick, advance motor simulation by 1/30th second: `obSimulatedMotor.advance_simulation(1.0/30.0)`
   - Assert at least 8 of 10 ticks returned a non-None TrackingSample
   - Assert at least one sample has `bPersonWasDetected == True`
   - Call `obTrackerController.stop_tracking_mode()`

2. `test_pipeline_creates_valid_tracking_samples(obSimulatedMotor, obSyntheticCamera, obTestConfig, obMockPoseTracker)`:
   - Same setup as above
   - Execute 5 ticks
   - For each non-None sample, verify:
     - `dSampleTimestampSeconds > 0`
     - `iSampleSequenceNumber >= 0`
     - `flPersonConfidenceScore >= 0.0`

3. `test_pipeline_tracks_person_center(obSimulatedMotor, obSyntheticCamera, obTestConfig, obMockPoseTracker)`:
   - Set mock pose tracker to return person at x=700 (off-center to the right)
   - Execute 5 tracking ticks with motor advancing
   - Verify motor target angle has changed from 0 (controller responded to off-center person)
