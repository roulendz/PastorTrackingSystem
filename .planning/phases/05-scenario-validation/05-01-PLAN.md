**Module-level constants:**
```python
_FL_FOV_DEGREES = 6.77
_I_WIDTH_PIXELS = 1280
_FL_DEGREES_PER_PIXEL = _FL_FOV_DEGREES / _I_WIDTH_PIXELS
_FL_PIXELS_PER_DEGREE = _I_WIDTH_PIXELS / _FL_FOV_DEGREES
_FL_CENTER_PIXEL = _I_WIDTH_PIXELS / 2.0  # 640.0
```

**Helper 1: `_build_scenario_sequences()`**
Convert angle-space waypoints to per-frame sequences for `_run_frames()`.

Input: list of waypoint tuples `(flAngleDegrees, flDurationSeconds)` or `(flAngleDegrees, flDurationSeconds, flConfidence)`. Default confidence is 0.9.

Logic:
- For each consecutive pair of waypoints, linearly interpolate angle from waypoint[i] to waypoint[i+1] over the duration of waypoint[i].
- Convert angle to pixel: `flPixel = _FL_CENTER_PIXEL + flAngleDeg * _FL_PIXELS_PER_DEGREE`
- For the last waypoint, hold position for its duration.
- Return `(vPixelXSequence, vConfidenceSequence, vDetectedSequence)`.
- Detection = True when confidence > 0.0, False when confidence == 0.0.
- Follow Pattern 1 from 05-RESEARCH.md precisely.

**Helper 2: `_run_scenario()`**
Wraps `_run_frames()` to handle per-frame confidence and detection sequences.

Signature:
```python
def _run_scenario(
    vWaypoints: list,
    obConfig: SystemConfiguration = None,
    flProportionalGain: float = 1.0,
    iWarmupFrames: int = 10,
) -> dict:
```

Logic:
1. Build sequences via `_build_scenario_sequences()`.
2. Create controller via `_build_test_controller()`.
3. Run warmup frames (person at first waypoint position, high confidence) to let OneEuroFilter initialize. Use `_run_frames()` with `flPersonX` at the pixel position of the first waypoint.
4. Run the scenario frame-by-frame in a custom loop (because `_run_frames` doesn't support per-frame confidence/detection sequences). For each frame:
   - Advance clock by frame interval
   - Update mock pose with `vPixelXSequence[i]`, `vConfidenceSequence[i]`, `vDetectedSequence[i]`
   - Update mock camera timestamp
   - Advance motor simulation
   - Execute tracking tick
   - Record `_flLastCommandedAngle`
5. Return dict: `{'vCommandedAngles', 'vExpectedAngles', 'vConfidences', 'vDetected', 'iWarmupFrames', 'obTracker', 'obMotor'}`
   - `vExpectedAngles`: the world-angle of the person at each frame (from the waypoint interpolation, in degrees)

**Helper 3: `_compute_scenario_rms()`**
Compute segmented RMS — only during frames where `bDetected=True` and after the warmup period.

Signature: `def _compute_scenario_rms(vCommandedAngles, vExpectedAngles, vDetected, sScenarioName="") -> dict`

Logic:
- For each frame where vDetected[i] is True, compute `abs(vCommandedAngles[i] - vExpectedAngles[i])`, convert to pixels via `/ _FL_DEGREES_PER_PIXEL`.
- Exclude frames where detection is False (hold/return frames) per Pitfall 5 in research.
- Return `{'flRmsPixels', 'flMaxPixelError', 'iWorstFrame', 'iTotalTrackingFrames'}`.

**Helper 4: `_assert_rms_within_tolerance()`**
Assert RMS is within 2.0 pixels with diagnostic failure message.

```python
def _assert_rms_within_tolerance(obResult: dict, sScenarioName: str, flTolerancePixels: float = 2.0):
    assert obResult['flRmsPixels'] < flTolerancePixels, (
        f"SYNC-06 FAILED: RMS = {obResult['flRmsPixels']:.2f} px (limit: {flTolerancePixels:.1f} px), "
        f"Max error = {obResult['flMaxPixelError']:.2f} px at frame {obResult['iWorstFrame']}, "
        f"Tracking frames = {obResult['iTotalTrackingFrames']}, "
        f"Scenario: {sScenarioName}"
    )
```
