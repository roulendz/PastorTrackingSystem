## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS DirectShow filter registry → discover_obs_camera_index | The set of friendly names returned by `pygrabber.dshow_graph.FilterGraph().get_input_devices()` is OS-trusted (registered system-wide by installers; admin required to register). A hostile filter using the exact friendly name `"OBS Virtual Camera"` would route through the discovery path. |
| `config.obs_camera_name` (operator-set) → discover_obs_camera_index | The string from `Config.obs_camera_name` is operator-set (no remote input) — exact case-sensitive equality is the gate. |
| pygrabber FilterGraph constructor → COM threading apartment | Constructing a real `FilterGraph` calls `CoInitialize(NULL)` (apartment-threaded). In pytest workers that already initialized COM with a different mode, this raises `RPC_E_CHANGED_MODE` (Pitfall 10). Mitigated via factory closure injection. |
