Contract:
- `start()` is single-shot; calling twice raises `CameraError(f"start() called twice (state={state.value})")`.
- `start()` blocks until the first valid `Frame` arrives via the capture thread, OR raises `CameraOpenError` after `_FIRST_FRAME_TIMEOUT_SEC=3.0` seconds. On timeout, `_stop_event` is set, capture thread is joined, source is released — no leaked handles.
- `frames()` yields `Frame` instances from a bounded `asyncio.Queue(maxsize=64)` with drop-oldest semantics; consumer-side stale-drop discards frames where age > 100 ms.
- `stop()` is idempotent in the sense that it tolerates being called from any non-DISCONNECTED state without raising; close-order is `_stop_event.set()` -> join thread (timeout) -> `source.release()` -> `_state = CLOSED` (Pitfall 7).
- `last_error` is `None` while running; populated with the typed `CameraError` subclass (`CameraOpenError` / `CameraStallError`) once a terminal failure latches.

            """Daemon-thread capture loop. -- IO-CAM-04 (timestamp + stall) + IO-CAM-03 (fallback)."""
            last_grab_ns: int | None = None
            p95_detector = _P95Detector(self._config.capture_fps)
            warmup_started_ns = time.perf_counter_ns()

                    return

                            threshold_ms=_STALL_THRESHOLD_NS / _NS_PER_MS,

                        return
                    last_grab_ns = None
                    continue

                try:
                    frame = Frame(
                        image=bgr,
                        width=self._current_width,
                        height=self._current_height,
                        timestamp_ns=now_ns,

                        "frame_shape_mismatch",
                        expected=f"{self._current_width}x{self._current_height}",
                        observed=str(getattr(bgr, "shape", "n/a")),
                        reason=str(exc),

                        self._fault_with_stall(reason=None)

           camera: ObsCamera,
           target_state: _CamState,
           timeout: float = 1.0,
       ) -> None:
           """Poll ``camera.state`` at 10 ms cadence until ``target_state`` or ``timeout``.
