```python
# ---------- combined stream (Phase 6 D-03 helper) ----------
async def stream(
    self,
    frames: AsyncIterator[Frame],
) -> AsyncIterator[tuple[Frame, list[Detection]]]:
    """D-03: Combine consume(frame) + detections() into a single (Frame, dets) iterator.

    Phase 6 orchestrator (per CONTEXT.md D-01..D-04) drives the tick loop as
    `async for frame, dets in detector.stream(camera.frames()):`. This helper
    is the SINGLE wiring seam between camera frames and detector output —
    drop-oldest at consume() ingress and clean StopAsyncIteration on
    detections() egress are both inherited from the existing surface.

    Yields (Frame, list[Detection]) tuples — the Frame is forwarded
    unchanged so the caller can update its `latest_frame` slot (D-17) AND
    extract `frame.timestamp_ns` (D-04) from the same yield, satisfying the
    single-task discipline (D-02 — no parallel camera-frames iterator).

    Exits cleanly when `frames` returns (StopAsyncIteration). Surfaces any
    latched PerceptionError via the underlying detections() egress.
    """
    detections_iter = self.detections()
    async for frame in frames:
        await self.consume(frame)
        # detections() yields one list per consumed frame (drop-oldest may
        # collapse multiple consumes into fewer yields — that is BL-01 by
        # design; the next __anext__ returns the most-recent result).
        try:
            dets = await detections_iter.__anext__()
        except StopAsyncIteration:
            return
        yield (frame, dets)
```
